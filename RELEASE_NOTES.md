# v0.1.0

The first release of `ghostsoap`, which prepares Australian Privacy Act requests to data brokers, recruiters and other businesses for you to send from your own mailbox. It makes no network connections.

- Executables for Linux (x86_64 and arm64, statically linked), macOS (arm64) and Windows (x86_64), so installing needs no Rust toolchain.
- Check a download before running it: compare it with `SHA256SUMS` and verify its signed build provenance with `gh attestation verify`.
